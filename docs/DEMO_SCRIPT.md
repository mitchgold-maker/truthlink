# Demo script

Target: 90-second video + live demo. Run on the deployed URL with the imported dataset. Two browser profiles: **Manager** and **Employee**.

| # | Who | Action | What the audience sees | Proves |
|---|---|---|---|---|
| 1 | Manager | Paste the kickoff meeting notes → "Extract tasks" | Draft tasks with owners, deadlines, skills, deliverables, each linked to the quote it came from → approve | AI turns talk into accountable work, human stays in control |
| 2 | Manager | Open Assignments / Team | Each person's tasks and load bar (assigned vs available hours) | Real workload from real records |
| 3 | Employee | Submit evidence on a binary task, then on a complex task | Binary: checks pass → **Complete**. Complex: criteria checklist → **AI Reviewed, pending approval** | Verification, and AI cannot self-approve complex work |
| 4 | Manager | Approve the complex task | Status → Complete; employee's profile gains a demonstrated skill | Verified history builds capability profiles |
| 5 | Manager | Put an employee on PTO | Their tasks turn at-risk; TruthLink recommends a replacement with reasons (demonstrated skill + free capacity) → approve | Knows who can get the rest done |
| 6 | Manager | Dashboard | Follow-up drafts for overdue / missing evidence (Slack post if built), recent activity with "Simulated" badges | Proactive follow-through |

**Security beat (if time):** as Employee, try to approve a complex task → blocked by the server.

**Pitch line:** "TruthLink knows what needs to get done, verifies what actually got done, and knows who can get the rest done."

Backup: record a clean run of steps 1–5 as soon as they work, in case the venue network fails.
